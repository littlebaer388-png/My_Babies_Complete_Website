How to publish on GitHub Pages:
1. Create/open your GitHub repository.
2. Upload EVERYTHING inside this folder, including the assets folder.
3. Commit the files.
4. Go to Settings > Pages.
5. Select Deploy from a branch, choose main and /root, then Save.

WhatsApp:
Open index.html and find:
const WHATSAPP_NUMBER = "";

Enter the business WhatsApp number in international format without +, spaces, or a leading 0.
Example South Africa: 27821234567

The website already has a WhatsApp pre-order button on every product.
